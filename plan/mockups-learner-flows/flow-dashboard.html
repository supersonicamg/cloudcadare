Data

  • Labs = completed lessons of type lab. Live classes = attendance rows against held live_sessions for the batch. Tests = passed month quizzes.
  • This week = the current week's items from the batch timetable plus lessons released this week, ticked from lesson_progress.
  • Tile counts are the whole program; "2 new" = published in the last 7 days and not opened.
  • Certificate checklist follows the course's completion rule (all lessons, month tests, capstone review).
