Choosing an EBS volume type

Snapshots and backups

Completed

gp3, io2, st1 or sc1? You’ll match each volume type to a real workload and see what changes in IOPS, throughput and price.

EBS volume types cheat sheetPDF · 240 KBAWS docs: EBS volume typesExternal link
Mark as completeNext: S3 storage classes →

A snapshot is a point-in-time copy of an EBS volume, stored in S3 behind the scenes. The first snapshot copies everything; every one after that copies only the blocks that changed.

Take one from the CLI

aws ec2 create-snapshot \
  --volume-id vol-0a1b2c3d4e5f67890 \
  --description "pre-upgrade backup"
Remember: a snapshot of a running volume is crash-consistent, not application-consistent. Pause writes or stop the instance for a clean copy.

Automate it

Use Data Lifecycle Manager to take snapshots on a schedule and delete old ones, so backups don’t quietly grow your bill.
